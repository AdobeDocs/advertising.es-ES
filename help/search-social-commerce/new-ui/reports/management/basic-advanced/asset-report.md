# [!UICONTROL Asset Report]

*Aplicable a [!DNL AI Max] campañas habilitadas en [!DNL Google Ads] cuentas solamente*

[!UICONTROL Asset Report] incluye datos de conversión de costo, clics y (opcionalmente) seguimiento de [!DNL Google] en el nivel de recurso para cada recurso generado por IA aplicable en las campañas habilitadas para [!DNL AI Max]. El informe no incluye conversiones de Adobe Analytics. Use este informe para priorizar los recursos que se van a mantener, pausar o reemplazar.<!-- Not included as of 7/22/26: You can optionally include advertiser-specific label classifications. -->

De forma predeterminada, los datos incluyen una fila para cada recurso aplicable (como logotipo, imagen, vídeo o titular) con al menos una métrica rastreada para cada unidad de tiempo en el intervalo de fechas especificado. Las filas están en orden ascendente por nombre de campaña de forma predeterminada.

Los datos de [!DNL Google Ads] suelen estar disponibles durante los 36 meses anteriores.
